# TYPOGENESIS

TYPOGENESIS is a mobile-first glyph-sequence game made with [sacred.computer](https://sacred.computer). It features an original 9×9 pixel-alien alphabet, procedural visuals, and evolving sequence recognition.

The project explores neuroscience concepts—including prediction, sensory processing, and error-driven learning—through interactive glyph sequences.

## Features

- Original, custom-designed 9×9 pixel-alien alphabet
- Progressive glyph-sequence gameplay
- Procedural visuals that respond to gameplay
- Mobile-first layout with on-screen glyph controls
- Optional physical-keyboard controls on desktop
- Micro Data Sheet with its own scrollable viewport and slim scrollbar
- Single-file implementation in `index.html`

## How to Play

1. Read the target glyph sequence.
2. Select the matching glyphs using the on-screen keybed.
3. Complete the sequence to advance.
4. Watch the visual field evolve as gameplay progresses.

On desktop, the physical-keyboard controls are **Q/W/E/R/A/S/D/F**, corresponding to the glyph-key positions. On mobile, use the on-screen controls; a physical keyboard is not required.

## Run Locally

No build step is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.

## Neuroscience Context

TYPOGENESIS uses sequence recognition as an interactive lens on predictive processing: the brain forms expectations about incoming sensory information and can update those expectations when a prediction error occurs. The game is an artistic exploration of these ideas, not a neuroscience measurement or clinical tool.
